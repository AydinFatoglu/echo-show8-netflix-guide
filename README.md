# Echo Show 8 Gen 1 — Netflix Kurulum Rehberi

Amazon Echo Show 8 Gen 1 (`crown`) üzerinde LineageOS 18.1 / Android 11 için Netflix 9.91.0 (74752) APKM kurulum rehberi.

## Görüntüle

`index.html` dosyasını tarayıcıda açın veya GitHub Pages ile yayınlayın. Sayfa Bootstrap CDN kullandığı için internet bağlantısı gerektirir.

## Doğrulanmış kurulum

- Cihaz: Echo Show 8 Gen 1 (`crown`), ARM32 `armeabi-v7a`
- Ekran yoğunluğu: **213 DPI (tvdpi)**
- Netflix: **9.91.0 build 10 (74752)**
- Gerekli APK parçaları: `base.apk`, `split_config.armeabi_v7a.apk`, `split_config.en.apk`, `split_config.tr.apk`, `split_config.tvdpi.apk`
- Özellikle `split_config.tvdpi.apk` eklenince uygulama kullanıcı testinde sorunsuz açıldı.

## Uyarı

Netflix APK dosyaları bu depoda **bulunmaz**. Yalnızca kurulum belgeleri paylaşılır. Netflix'in hizmet şartları, telif hakları ve cihaz uyumluluğu koşulları geçerlidir. Bu kurulumun farklı cihazlarda çalışacağı garanti edilmez.

## GitHub Pages

GitHub deposunda **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** seçin.
