Adım adım kurulum

1 ADB bağlantısını ve ekran yoğunluğunu doğrula

PowerShell'de çalıştırın. Çıktıda cihazın bağlı, ABI'nin armeabi-v7a, fiziksel yoğunluğun 213 olduğunu doğrulayın.

$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb devices
& $adb shell getprop ro.product.cpu.abilist
& $adb shell wm density

2 APKM arşivini ayıkla

APKM, ZIP tabanlı arşivdir. Aşağıdaki kod belirtilen paketi geçici çalışma klasörüne çıkarır.

$apkm = 'C:\Users\a_fatoglu\Desktop\6_6 upgrades\com.netflix.mediaclient_9.91.0_build_10_74752-74752_4arch_7dpi_24lang_fb64db970c14fb994147849f979da5df_apkmirror.com.apkm'
$work = Join-Path $env:TEMP 'Netflix_APKM_Compare'
if (-not (Test-Path -LiteralPath $apkm)) { throw "APKM bulunamadi: $apkm" }
if (Test-Path $work) { Remove-Item $work -Recurse -Force }
New-Item -ItemType Directory -Path $work -Force | Out-Null
Add-Type -AssemblyName System.IO.Compression.FileSystem
[System.IO.Compression.ZipFile]::ExtractToDirectory($apkm, $work)
Get-ChildItem $work -Filter '*.apk' -Recurse | Select-Object Name

Bu cihazda başarıyla çalışan kurulum aşağıdaki parçaları birlikte içerir:

ARM64 veya x86 split dosyalarını yüklemeyin. hdpi yerine cihazın 213 DPI değerine karşılık gelen tvdpi kullanın.

4 Beş parçayı birlikte kur

Bu komut mevcut Netflix sürümünü kaldırmadan aynı sürümün beş split parçasını birlikte kurar. -r uygulama verilerini korur. Başka sürüm/imza kuruluysa işlem başarısız olabilir; bu durumda hata mesajını inceleyin.

$ErrorActionPreference = 'Stop'
$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
$work = Join-Path $env:TEMP 'Netflix_APKM_Compare'
$names = @('base.apk','split_config.armeabi_v7a.apk','split_config.en.apk','split_config.tr.apk','split_config.tvdpi.apk')
$apks = foreach ($name in $names) {
    $matches = @(Get-ChildItem -LiteralPath $work -Recurse -File | Where-Object Name -eq $name)
    if ($matches.Count -ne 1) { throw "Beklenen tek APK bulunamadi: $name (adet: $($matches.Count))" }
    $matches[0].FullName
}
& $adb install-multiple -r @apks
if ($LASTEXITCODE -ne 0) { throw 'Kurulum basarisiz.' }
& $adb shell pm path com.netflix.mediaclient

5 Netflix'i doğrudan başlat

Bu sürümde genel LAUNCHER intent'i çözümlenemediği için testte doğrudan Activity başlatıldı.

$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb shell am force-stop com.netflix.mediaclient
& $adb shell am start -n 'com.netflix.mediaclient/.ui.launch.UIWebViewActivity'

Kurulum doğrulama

$adb = "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe"
& $adb shell dumpsys package com.netflix.mediaclient | Select-String 'versionName=|versionCode='
& $adb shell pm path com.netflix.mediaclient

Beklenen sürüm 9.91.0 build 10 74752; pm path çıktısında beş dosya ve özellikle split_config.tvdpi.apk görünmeli.

Gözlemlenen sonuç: Beşinci split eklendikten sonra Netflix uygulaması sorunsuz açıldı. Oturum açma, katalog görüntüleme ve video oynatma bu kayıtta ayrıca doğrulanmadı.

Sorun giderme

Önce adb shell pm path com.netflix.mediaclient çıktısını inceleyin. Testimizde split_config.tvdpi.apk eksikti. Beş APK'yı install-multiple -r ile birlikte yüklemek açılış sorununu çözdü.

Genel MAIN/LAUNCHER çağrısı yerine adb shell am start -n com.netflix.mediaclient/.ui.launch.UIWebViewActivity kullanın.

Önceki loglarda Widevine L1 başlatma başarısı yanında usage table oluşturma hataları da görüldü. Uygulamanın açılması DRM lisansı veya video oynatmanın doğrulandığı anlamına gelmez. DRM sistem dosyalarını bu kurulum için değiştirmeyin.
